## 🌟 Ключевые возможности

- 🚀 **Браузерная автоматизация (Playwright)**: Работает напрямую через ваш профиль HeadHunter. Не требует покупки платного API работодателя — сессия сохраняется в защищенном профиле Chromium/Chrome.
- 🧠 **Умный ИИ-анализ вакансий (Match Score 0–100%)**: Оценивает совпадение стека технологий, грейда и опыта с помощью моделей **Google Gemini** (`gemini-3.6-flash`, `gemini-2.5-flash`, `gemini-2.5-pro`) и **Mistral AI** (`mistral-small-latest`, `mistral-large-latest`).
- 🔄 **Отказоустойчивость и ротация ключей**:
  - Поддержка пула нескольких API-ключей с автоматическим переключением при исчерпании лимитов (`429 Too Many Requests`).
  - Мгновенный Fallback с Gemini на Mistral AI (и наоборот) без прерывания сканирования.
- 🎯 **Мульти-резюме (Автовыбор ИИ)**: Если у вас несколько резюме на hh.ru (например, *Python Backend*, *Team Lead*, *ML Engineer*), нейросеть выберет наиболее релевантное резюме под конкретную вакансию.
- ✍️ **Персонализированные сопроводительные письма**:
  - Генерация кратких (3–5 предложений), емких писем строго под требования вакансии.
  - Никаких шаблонных фраз («Прошу рассмотреть...», «Стрессоустойчивый...») и выдуманного опыта.
- ❓ **Автоматические ответы на вопросы работодателя**:
  - ИИ анализирует вопросы скрининга (зарплата, удаленка, локация, опыт со стеком, готовность к тестовому) и отвечает на основе профиля кандидата.
  - **Режим проверки (`needs_answers`)**: если ИИ не уверен в ответе (<85%), вакансия попадает на подтверждение пользователю.
- ⚡ **Быстрый отклик по ссылке (Quick Apply)**: Вставьте ссылку на любую понравившуюся вакансию в интерфейс — ИИ мгновенно оценит её, подберет резюме, ответит на вопросы и отправит отклик.
- 🛡 **Безопасный режим (Dry Run)**: Возможность запуска в режиме симуляции для предварительного просмотра оценок и сгенерированных писем без реальной отправки откликов.
- 🖥 **Современный Dark UI**: Нативное десктопное приложение (PyWebview + FastAPI) с красивым неоновым интерфейсом, статистикой, фильтрацией и редактируемым системным промптом.

## 📦 Установка и запуск

### Требования
- **Python 3.11+**
- Установленный браузер **Google Chrome** или **Microsoft Edge**

### 1. Клонирование репозитория
```bash
git clone https://github.com/andreimelneichuk/hh_ai_applier.git
cd hh_ai_applier
```

### 2. Создание виртуального окружения и установка зависимостей
```bash
# Создание venv
python3 -m venv venv

# Активация (macOS / Linux):
source venv/bin/activate

# Активация (Windows PowerShell / CMD):
# venv\Scripts\activate

# Установка зависимостей
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Настройка API-ключей нейросетей
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Заполните ключи в `.env` (или укажите их позже прямо в интерфейсе в разделе «Настройки»):
```env
# Gemini API Key (бесплатно в Google AI Studio: https://aistudio.google.com/)
GEMINI_API_KEYS=AIzaSy...,AIzaSy...
GEMINI_MODEL=gemini-3.6-flash

# Mistral API Key (опционально, https://console.mistral.ai/)
MISTRAL_API_KEYS=your_mistral_api_key
MISTRAL_MODEL=mistral-small-latest
```

## 🚀 Запуск приложения

### Десктопный режим (GUI)
```bash
python desktop.py
```
Откроется нативное окно приложения.

### Консольный режим (CLI)
```bash
python main.py
```

### Запуск только веб-сервера (для работы через обычный браузер)
```bash
python -m uvicorn src.api.app:app --host 127.0.0.1 --port 8000 --reload
```
Интерфейс будет доступен по адресу: `http://localhost:8000`.

## 📖 Руководство пользователя (Инструкция по шагам)

### 1. Первоначальный вход в аккаунт hh.ru
1. Запустите приложение удобным способом (`python desktop.py` или собранный файл `.app` / `.exe`).
2. В левой панели в блоке **«Аккаунт HeadHunter»** нажмите кнопку **«Открыть браузер для входа»**.
3. В открывшемся окне браузера войдите в свой профиль hh.ru (через пароль, SMS-код или почту).
4. Закройте окно браузера. Приложение автоматически подгрузит данные профиля: ваше имя, почту и список резюме.
> [!TIP]
> Сессия сохраняется в защищенном профиле Playwright (`~/Library/Application Support/HH_AI_Applier/playwright_session` на macOS или `%APPDATA%/HH_AI_Applier/playwright_session` на Windows). При следующих запусках приложения повторная авторизация **не требуется**.

---

### 2. Настройка параметров подбора
В блоке **«Настройки подбора»** в левой панели:
* **Резюме для рекомендаций и откликов**:
  * Выберите нужное резюме из вашего аккаунта hh.ru.
  * Если у вас создано несколько резюме, ИИ автоматически подберет наиболее релевантное для каждой конкретной вакансии.
* **Доп. ключевые слова (необязательно)**:
  * **Рекомендуемый вариант (пустое поле)**: ИИ будет анализировать умные персональные рекомендации самого HeadHunter, сформированные на базе выбранного резюме.
  * **Точечный поиск**: введите через запятую ключевые запросы (например: `Python developer, FastAPI, Backend, TechLead`).
* **Регион поиска**: выберите регион поиска вакансий (Россия, Москва, Санкт-Петербург, Пермь и т.д.).
* **Порог соответствия (Match Score)**:
  * Ползунком установите минимальный процент совпадения (по умолчанию **75%**).
  * Вакансии с оценкой ниже порога будут автоматически отсеиваться с фиксацией причины в истории.
* **Безопасный режим (Dry Run)**:
  * Рекомендуется включать **при первых запусках**.
  * В режиме Dry Run ИИ полноценно анализирует вакансии, оценивает стек и пишет сопроводительные письма, но **не отправляет реальные отклики на hh.ru**.
* Нажмите **«Сохранить настройки»**.

---

### 3. Заполнение базы ответов (FAQ) кандидата
Работодатели на hh.ru часто прикрепляют анкеты и тесты при отклике (зарплатные ожидания, формат работы, локация, готовность к тестовым заданиям, наличие ИП/самозанятости, военный билет и т.д.).

1. В левой панели нажмите кнопку **«📋 База ответов (FAQ)»**.
2. Добавьте готовые ответы для ИИ:
   * **Тема / Ключ**: например `salary`, `remote`, `relocation`, `test_assignment`.
   * **Название вопроса**: понятная формулировка (например, *«Зарплатные ожидания»*).
   * **Ваш ответ**: как отвечать работодателю (например, *«От 250 000 руб. на руки, готов обсудить в зависимости от задач»*).
3. Нажмите **«Сохранить ответ»**. ИИ будет использовать эти данные при заполнении вопросов работодателей при откликах.

---

### 4. Настройка LLM, провайдеров и пула API-ключей
Нажмите кнопку **«⚙️ Настройки LLM и промпта»** в боковой панели или в шапке дашборда.

#### Вкладка «Модели и параметры»:
* **Модели**:
  * **Gemini (Основная)**: `gemini-3.6-flash` (быстрая и экономичная, рекомендуется), `gemini-3.5-flash`, `gemini-3.1-pro-preview`.
  * **Mistral (Резервная)**: `mistral-small-latest`, `mistral-large-latest`, `codestral-latest`.
* **Основной LLM провайдер**: переключение между Gemini API и Mistral AI.
* **Температура генерации**: рекомендуется `0.20` для строгого, точного анализа стека без галлюцинаций.
* **Автоматический Fallback**: при превышении лимитов (`429 Too Many Requests`) система автоматически переключится на резервного провайдера без остановки сканирования.
* **Менеджер API-ключей**:
  * Добавьте несколько бесплатных ключей Gemini (получить можно в [Google AI Studio](https://aistudio.google.com/)) и ключей [Mistral AI](https://console.mistral.ai/).
  * При исчерпании лимитов одного токена приложение автоматически перейдет на следующий ключ из пула.
  * Нажмите кнопку **«🔄 Проверить доступность всех»**, чтобы протестировать валидность каждого ключа.

#### Вкладка «Промпт классификации»:
* **Промпт классификации**: вы можете редактировать инструкцию для нейросети, задавать жесткие правила отсева (например, строгий отказ от легаси-технологий или онсайт-формата). Доступны переменные шаблона: `{resume_text}`, `{skills}`, `{company}`, `{salary}`, `{experience}`, `{threshold}` и др.
* **Постфикс сопроводительного письма**: укажите ваши контакты и ссылки (Telegram, телефон, профиль GitHub / портфолио) — они будут автоматически дописываться в конце каждого сгенерированного письма.

---

### 5. Запуск сканирования и работа с дашбордом
1. Нажмите кнопку **«Запустить сканирование»** внизу левой панели.
2. Вверху появится баннер обработки в реальном времени с отображением текущей анализируемой вакансии.
3. Процесс можно в любой момент приостановить кнопкой **«⏹ Остановить анализ»**.

#### Разбор карточек и фильтров:
* 🟢 **Подошли (Match)** — вакансии с оценкой выше заданного порога. При выключенном Dry Run отклик отправляется автоматически.
* 🟡 **Вопросы ❓ (needs_answers)** — вакансии, где работодатель задал сложные вопросы, и уверенность ИИ в ответе была < 85%:
  1. Кликните на такую вакансию в списке.
  2. В открывшемся окне проверьте предложенные ИИ ответы на вопросы анкеты и при необходимости отредактируйте их.
  3. Проверьте и при желании скорректируйте сопроводительное письмо.
  4. Нажмите **«Откликнуться сейчас»**.
* 🔵 **Отправлено** — вакансии, на которые отклик успешно доставлен работодателю.
* ⚪ **Не подошли** — вакансии, не прошедшие порог соответствия. Кликните по вакансии, чтобы прочитать подробную аргументацию ИИ (*Reasoning*), почему опыт или стек не подошли.
* 🔴 **Ошибки ↺ (failed)** — вакансии, при обработке которых произошел сбой сети или API. Нажмите **«↺ Переоценить все ошибки»** для их повторного прогона.

---

### 6. ⚡ Быстрый отклик по ссылке (Quick Apply)
Если вы нашли вакансию на hh.ru вручную и хотите отправить точечный отклик с ИИ:
1. Скопируйте ссылку на вакансию из адресной строки браузера (или её числовой ID).
2. Вставьте в поле **«⚡ Вставьте ссылку на вакансию hh.ru...»** в верхней части дашборда.
3. Нажмите **«Откликнуться с ИИ»**.
4. Нейросеть моментально загрузит описание, подберет наиболее подходящее резюме, сгенерирует ответы на вопросы работодателя, подготовит индивидуальное сопроводительное письмо и отправит отклик.

### 7. 🖥 Консольный режим (CLI / Планировщик)
Для автоматизации на удаленном сервере или периодического запуска без графического интерфейса:
1. Укажите параметры в файле `.env` (API-ключи, `SEARCH_QUERIES`, `SEARCH_AREA`, `MATCH_THRESHOLD`, `DRY_RUN`).
2. Запустите:
   ```bash
   python main.py
   ```
3. Скрипт можно поставить на регулярный автозапуск через **cron** (macOS / Linux) или **Планировщик заданий Windows** (Task Scheduler).

### 💡 Полезные советы и рекомендации
* **Лимиты hh.ru**: Платформа HeadHunter ограничивает количество откликов (до 200 откликов в сутки на аккаунт). Приложение бережно соблюдает задержки между запросами.
* **Качество откликов**: Установка порога `MATCH_THRESHOLD` в районе **75–85%** обеспечивает максимальную конверсию в приглашения на интервью, отсекая нерелевантные позиции.
* **Логи работы**: Подробный журнал работы пайплайна сохраняется в файл `applier.log` в корне проекта.

## 🛠 Сборка бинарных файлов (.app / .exe)
